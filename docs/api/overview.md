# API Reference

WOG Dump works as a library: every CLI command is a thin wrapper over
the `core` package. The dependency direction is strictly one-way,
`cli -> core -> utils`.

```python
from wog_dump.core.catalog import build_catalog
from wog_dump.core.config import get_config

entries = build_catalog(get_config())
for entry in entries:
    if entry.scene:
        print(entry.name, entry.size_bytes)
```

Pages in this section group the modules by concern. Docstrings are the
source of truth; the extraction is generated by
[mkdocstrings](https://mkdocstrings.github.io/).
