# WOG Dump

Extract and rebuild 3D weapon models from
[World of Guns: Gun Disassembly](https://store.steampowered.com/app/262410/).
One command turns the in-game AK-47 into a Blender-ready glTF scene with
the exact part hierarchy, game materials and studio lighting.

- Personal, educational and research use. Extracted assets remain the
  property of Noble Empire Corp.
- Python 3.12+, install with `pip install wog-dump`.
- Source: [github.com/InzGIBA/ReWOG](https://github.com/InzGIBA/ReWOG).

Start with [Getting started](quickstart.md), then browse the
[API Reference](api/overview.md) if you want the library surface.
