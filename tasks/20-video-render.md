# T-20: Видеорендер (turntable, анимации сборки)

- **Статус:** не начата
- **Приоритет:** low
- **Оценка:** M
- **Зависимости:** T-05 (превью-рендеры, инфраструктура headless
  Blender), T-02 (glTF-анимации — для рендера анимации сборки)
- **Квартал roadmap:** Q4 2027

> Базовые задачи должны быть в статусе «готово» до старта этой.

## Цель

Продвинуть превью-рендеры T-05 до видео: плавный turntable-ролик
оружия и (если есть анимации T-02/T-17) видео сборки/разборки.
Готовый контент для релизных анонсов, статей и демонстрации
проекта.

```bash
wog-dump render ak47 --video                # turntable MP4
wog-dump render ak47 --video --clip assembly # видео анимации сборки
wog-dump render ak47 --video --gif          # GIF вместо MP4
```

## Контекст: что будет доступно после базовых задач

- T-05: `core/render.py::RenderManager` — поиск Blender, генерация
  скриптов, subprocess-запуск, обработка ошибок; шаблон turntable.
- T-02: GLB с animation-треками (`build-scene --animations`);
  Blender импортирует glTF-анимации в Action-ы — рендер-скрипт
  может проиграть таймлайн.

## Требования

### Функциональные

- `--video` у команды `render` (T-05): turntable — камера делает
  полный оборот вокруг оружия; параметры `--duration SEC` (дефолт
  10), `--fps` (дефолт 30), `--size PX` (дефолт 1920×1080;
  квадрат — опция `--square`).
- `--clip <name>`: рендер указанной анимации из GLB (список клипов
  — по манифесту `scene.json`; несуществующее имя — ошибка со
  списком доступных). Длительность = длительность клипа, `--duration`
  игнорируется с предупреждением.
- Формат: MP4 (H.264) встроенным ffmpeg Blender; `--gif` — GIF
  через Pillow из последовательности кадров (Blender рендерит PNG,
  склейка отдельно — путь уже опробован в T-05).
- Вывод: `runtime/scenes/<weapon>/renders/turntable.mp4` /
  `<clip>.mp4`.
- Отсутствие анимаций в сцене при `--clip`: подсказка пересобрать
  сцену с `--animations` (указание точной команды).

### Нефункциональные

- Переиспользуется вся инфраструктура T-05 (поиск Blender, ошибки,
  временные скрипты); новые шаблоны скриптов кладутся рядом с
  шаблоном T-05 в `resources/`.
- Рендер долгий: прогресс по кадрам в stderr (счётчик `frame 45/300`),
  summary в конце.

## План реализации

1. Шаблон `resources/render_video.py`: импорт GLB, NLE-настройка
   (camera path / clip playback: установить action на таймлайн,
   `scene.frame_start/end`), цикл кадров, вывод через
   `bpy.ops.render.render(write_still)` + ffmpeg encode или
   PNG-последовательность для GIF.
2. `RenderManager`: режимы video/clip, парсинг манифеста за клипами,
   прогресс-вывод из stdout Blender.
3. CLI-флаги `--video/--clip/--gif/--duration/--fps` в `cli/render.py`.
4. README: встроить сгенерированный пример-видео (релизные notes).

## Критерии приёмки

- [ ] `render ak47 --video` даёт играющий MP4 полного оборота
      заданной длительности
- [ ] `--clip assembly` рендерит анимацию из GLB, собранного с
      `--animations`; длительность видео = длительности клипа
- [ ] `--gif` даёт зацикленный GIF
- [ ] Без Blender / без анимаций — понятные ошибки с точными
      следующими шагами, exit 1
- [ ] Прогресс кадров виден в терминале; долгий рендер можно
      прервать Ctrl+C без мусорных процессов (подпроцесс гасится)

## Тесты

- `tests/unit/test_render.py` (расширение): генерация скриптов для
      обоих режимов (фиксированные вставки: fps, длительность,
      имя клипа), парсинг манифеста клипов, ошибки отсутствия
      анимаций.
- Integration (skip без Blender): turntable на синтетическом кубе-
      GLB (GLBWriter из тестовых фикстур) — 2-секундное видео
      ненулевого размера.
