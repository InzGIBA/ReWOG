# Tasks — технические задачи ReWOG (roadmap 2027)

Подробные постановки задач по [roadmap 2027](../README.md). Каждая задача —
отдельный файл, самодостаточный: контекст, требования, план, критерии приёмки,
тесты и риски описаны внутри файла, без обязательного чтения соседних задач.

## Конвенции

- **Именование:** `NN-slug.md`. Номер фиксирует только порядок сортировки:
  задачи `01–16` независимы и могут выполняться в любом порядке или параллельно;
  задачи `17–21` зависят от более ранних (базовая задача всегда раньше зависимой).
- **Приоритет:** `high` — заметно меняет ценность продукта; `medium` — важно,
  но не срочно; `low` — полировка и экосистема.
- **Оценка:** `S` — до 3 дней, `M` — 1–2 недели, `L` — 3+ недели (чистое время).
- **Статус:** обновляйте строку `Статус:` в шапке файла и колонку в таблице:
  `не начата` → `в работе` → `на ревью` → `готово`.

## Правила зависимостей

Задача с непустой колонкой «Зависимости» стартует только после перевода
базовых задач в статус `готово` (или после явного решения взять зависимость
в сокращённом виде — тогда это фиксируется в разделе «Риски» зависимой задачи).
Остальные задачи можно делать в любом порядке.

## Связь с горизонтальными темами roadmap

Две темы идут фоном весь год и не оформлены отдельными задачами:

1. **Дрейф протокола.** Каждый релиз — ручная проверка `13-protocol-probe.md`
   против живого API; при смене протокола игры — обновление фикстур тестов.
2. **Реальные bundle-фикстуры.** Постепенно добавлять маленькие обфусцированные
   куски реальных бандлов в `tests/fixtures/` для golden-тестов экстракторов.
